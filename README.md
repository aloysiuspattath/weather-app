# NexusWX (Weatherly) 🌩️

NexusWX is a premium, open-source weather and news hub built with React and Vite. It features a stunning "glassmorphism" UI, dynamic cinematic video backgrounds based on live weather conditions, and a comprehensive global news aggregator.

## Features
- 🌦️ **Live Weather Data**: Powered by Open-Meteo (100% free, no API keys).
- 🎥 **Cinematic Backgrounds**: High-quality video loops that dynamically change based on current weather (rain, snow, sunny, cloudy, etc).
- 📰 **Global News Hub**: Aggregates local, state, national, and international weather & climate news.
- 🗺️ **Advanced Maps**: Live global rain radar powered by RainViewer.
- 💎 **Premium UI**: Apple Vision Pro-style glassmorphism, responsive CSS Grid layout, and polished typography.

## Quick Start
1. Clone the repository
2. Run `npm install`
3. Run `npm run dev` to start the development server.

## Built With
- React + Vite
- Lucide React (Icons)
- Recharts (Forecast charts)
- React-Leaflet (Interactive Maps)
